# Хроники Элдервуда — Android-проект (альфа)

Это Android Studio-проект, который упаковывает текущую HTML5-версию игры в полноэкранное Android-приложение. Игра запускается офлайн из ресурсов приложения; отдельный браузер пользователю не нужен. Встроенное хранилище WebView позволяет игре использовать localStorage для сохранений.

## Как получить APK
1. Установить Android Studio на компьютер и открыть эту папку как проект.
2. Дождаться Gradle Sync (нужен интернет для загрузки Android Gradle Plugin и SDK, если их ещё нет).
3. В Android Studio выбрать **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Для установки на свой телефон перенести этот APK и открыть его; Android может попросить разрешить установку из выбранного источника.

## Как подготовить публикацию в Google Play
Для Google Play обычно нужен подписанный Android App Bundle (AAB): **Build → Generate Signed Bundle / APK → Android App Bundle**. Создать отдельный ключ подписи и хранить его резервную копию в безопасном месте. Не отправлять keystore и пароли посторонним.

Перед публикацией нужно проверить игру на реальных устройствах, заполнить страницу приложения, добавить графику и скриншоты, указать возрастной рейтинг и сведения о данных/конфиденциальности, пройти проверки Play Console и выполнить требования Google Play, действующие на дату загрузки. Публикация не гарантирует, что приложение навсегда останется в магазине: нужно соблюдать правила и требования к обновлениям.

## Важно
- Это альфа-сборка: проект подготовлен, но APK здесь не собран и игра не прошла полноценное тестирование на Android-устройствах.
- Текущая версия игры — HTML/JavaScript внутри WebView, а не нативная 2D-игра на игровом движке.
- Прогресс хранится локально на устройстве. Очистка данных приложения или удаление приложения может стереть сохранение.
- Идентификатор приложения: `com.elderwood.chronicles`. Версия: `1.0.0-alpha`.
- Ориентация приложения зафиксирована в альбомной.

## Сборка APK без Android Studio (через GitHub Actions)
В проект добавлен workflow `.github/workflows/android-apk.yml`.
1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки проекта (не ZIP-файл как один документ, а именно распакованные папки и файлы).
2. Открой репозиторий → вкладка **Actions**.
3. Выбери **Build Chronicles of Elderwood APK** → **Run workflow**.
4. Дождись зелёной галочки у запуска. Открой завершённый запуск и внизу страницы найди **Artifacts**.
5. Скачай `chronicles-of-elderwood-debug-apk`, распакуй скачанный архив и найди `app-debug.apk`.
6. Перенеси APK на Android и открой его для установки. Если Android спросит, разреши установку приложений из того приложения, которым открываешь APK.

Это тестовая debug-сборка для установки и проверки на своём устройстве, не готовый релиз для Google Play. Для Google Play нужен отдельный подписанный release AAB, проверка приложения и оформление Play Console взрослым владельцем аккаунта.
